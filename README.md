# 🌍 Climate Change Impact Analysis - Boisar

## Project Overview

This is an interactive web-based platform for analyzing climate change impacts at the local level in Boisar. The project combines community engagement with data visualization to help residents understand and respond to climate challenges.

## Features

### 🎯 Core Components

1. **Interactive Dashboard**
   - Real-time climate metrics display
   - Key performance indicators (Temperature, Rainfall, Water Availability, Air Quality)
   - Beautiful metric cards with trend indicators

2. **Data Visualization Charts**
   - **Monthly Temperature Trend** (Line Chart) - Shows current vs historical averages
   - **Rainfall Pattern** (Bar Chart) - Monthly rainfall distribution
   - **Water Availability Status** (Doughnut Chart) - Water stress levels
   - **Air Quality Distribution** (Pie Chart) - Air quality categories
   - **Year-over-Year Temperature Comparison** (Bar Chart) - Multi-year analysis
   - **Seasonal Climate Patterns** (Radar Chart) - Seasonal variations

3. **Climate Impact Analytics Section**
   - Detailed analysis cards for each climate parameter
   - Temperature analysis with trend data
   - Rainfall variability and extreme event tracking
   - Water stress index calculations
   - Environmental health metrics

4. **Community Engagement**
   - Integrated Google Form for collecting survey responses
   - Impact area cards highlighting major concerns
   - Call-to-action sections encouraging participation

5. **Responsive Design**
   - Mobile-friendly layout
   - Adaptive grid systems
   - Touch-friendly navigation
   - Smooth animations and transitions

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Charting**: Chart.js 3.9.1
- **Styling**: Modern CSS with Flexbox and Grid
- **Data Integration**: Google Forms (embedded)
- **Animations**: CSS animations and JavaScript transitions

## Data Representation

### Temperature Data
- Monthly averages ranging from 25°C (January) to 38°C (July)
- Historical comparison showing 0.46°C/year increase trend
- 12 heat wave events recorded in 2024

### Rainfall Data
- Monsoon-dependent (65% of annual rainfall)
- Peak rainfall: 180mm in July
- 15% decrease vs historical average

### Water Availability
- 62% available (green)
- 28% stressed (yellow)
- 10% critical (red)

### Air Quality
- 15% Good days
- 35% Moderate days
- 35% Poor days
- 15% Very Poor days
